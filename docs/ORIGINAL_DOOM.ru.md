# Оригинальная графика Doom

В репозитории и в готовых релизах нет данных Doom. Чтобы получить оригинальный вид, соберите данные у себя из шареварного эпизода
(или из своей копии `DOOM1.WAD`). Результат только для вашего прибора: не публикуйте его (см. [NOTICE](../NOTICE.md)).

1. Сначала сделайте резервную копию, как в [README](../README.ru.md#установка) (`SG004_NORBACKUP.bin`, сохраните `NOR.BIN`).
2. Соберите с вашей копией, либо из скачанного шареварного WAD (архив и WAD проверяются по SHA-256/SHA-1)

   ```sh
   scripts/build.sh original --backup NOR.BIN
   ```

   либо из имеющегося шареварного `DOOM1.WAD` 1.9 (платный `DOOM.WAD` не пробовался)

   ```sh
   scripts/build.sh original --wad /путь/к/DOOM1.WAD --backup NOR.BIN
   ```

   Скрипт вырезает экраны, которых в игре с одной картой не видно (статистика уровня, справка, титры, финал), конвертирует E1M1
   в пакет около 1,06 МБ и собирает `out/doom.uf2` и `out/SG004_DOOM.bin`. Чтобы пакет поместился, конвертер может понизить
   разрешение спрайтов монстров.
3. Установка как для Freedoom: `out/SG004_NORLOAD.bin`, затем `out/doom.uf2` на его диск, затем `out/SG004_DOOM.bin`.

Если Freedoom уже установлен, просто загрузите новые `doom.uf2` и `SG004_DOOM.bin` поверх. Загрузчик сотрёт нужные сектора, а игра
проверяет, что обе половины данных из одной сборки, и пишет об этом на экране, если нет (например, если скопирован только
`SG004_DOOM.bin`).

Пакет не поместится, если взять другую карту или добавить текстуры: область данных 1 073 152 байта
(`firmware/doom/game/sg_layout.h`, `--capacity` в `scripts/build.sh`). Конвертер выводит размер и останавливается, если не влезает.
